# Guia de Negócios do Conecta

Página link-na-bio dos negócios nucleados do Conecta (Gravataí/RS), no padrão
visual do Conecta (marinho + turquesa). Lista por categoria, com botões de
Instagram, WhatsApp (mensagem personalizada) e Site.

- **No ar:** https://guiaconecta.netlify.app/
- **Fonte:** `index.html` (arquivo único, autossuficiente — fontes e imagens
  embutidas em base64).

## Publicar (Netlify)
Site estático de uma página. Publish directory = raiz (`.`). Sem build.
Conectado a este repositório → cada commit publica automaticamente.
